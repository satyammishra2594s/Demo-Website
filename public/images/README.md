# Client photo slots

Drop the restaurant's approved photos into this folder using these names. The website tries the local photo first and uses a real-photo Unsplash placeholder if the file is not present.

## Hero
- `hero.jpg` — wide interior / warm dining-room photo, ideally 2000px wide.
- `hero.mp4` — optional muted, seamless 8–12 second ambient video. Keep it compressed (H.264 MP4, no audio). The still image remains the fallback.

## Ambience gallery
- `ambience-1.jpg` — dining room / wide interior
- `ambience-2.jpg` — spice and ingredient close-up
- `ambience-3.jpg` — chef or kitchen preparation
- `ambience-4.jpg` — table setting / service moment
- `ambience-5.jpg` — guests sharing a meal (with permission)
- `ambience-6.jpg` — restaurant detail / signature spread

## Menu image slots
Every menu item has its own optional image slot: `dish-<dish-name>.jpg`. Use the dish name in lowercase and replace spaces / punctuation with single hyphens. For example:
- `dish-paneer-tikka.jpg`
- `dish-butter-chicken.jpg`
- `dish-hyderabadi-veg-dum-biryani.jpg`
- `dish-mango-lassi.jpg`

The current set of 96 names and filenames is generated by `src/data/menu.js`. If a specific dish photo is not supplied, the website falls back to a relevant category photograph. Use landscape photos, consistent warm white balance and natural restaurant lighting. Avoid AI-generated food imagery. Fallback photos are temporary placeholders, not claims about Desi Spices' actual premises or dishes.
